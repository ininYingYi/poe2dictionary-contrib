# Abyss

Abyss receives a smaller but important 0.5.0 refresh: clearer Atlas
cracks, guaranteed Abyssal Depths boss progression, and a revamped Atlas
tree.

![Abyss](./map.webp)

## What changed

- Large Abyss cracks now appear on the Atlas.
- Completing Atlas Abysses closes the cracks.
- Completing an Atlas Abyss always grants an 
**Abyssal Depths** with a boss fight.
- The Abyss Atlas Tree was revamped with many new nodes and changes to
existing nodes.
- Kulemak's Invitation is now always allocated to the map owner.

## Reward and balance notes

- Abyss Omens no longer drop in areas below level 65.
- Modifiers to the number of chests now apply to Abyss chests.
- Those chest modifiers also affect the chance to find Abyssal Depths,
so more chests no longer reduce Depths chance.
- The Meteoric Demise monster modifier had its damage adjusted.
- Lithomantic Runes from the Abyss monster modifier now activate after a
longer delay.
