# Useful POE2 Tools

This page collects external Path of Exile 2 websites that are useful for
checking data, planning builds, pricing items, crafting, trading, and
preparing loot filters. Most of them are community tools, so double-check
league, patch, and economy data before making expensive decisions.

## Best first stops

- **[Official Trade Site](https://www.pathofexile.com/trade2)**: 
the safest starting point for buying gear, checking live listings, and
searching exact item affixes.
- **[PoE2DB](https://poe2db.tw/us/)**: 
fast reference for items, gems, modifiers, monsters, quests, Atlas
data, and datamined patch details.
- **[poe.ninja POE2](https://poe.ninja/poe2)**: 
economy and build snapshots for seeing what players are actually using
and how prices are moving.
- **[Path of Building Community](https://pathofbuilding.community/)**: 
the main build planner for comparing passive trees, gear, gems,
damage, and defenses.

## Build planning

- **[Path of Building PoE2 GitHub](https://github.com/PathOfBuildingCommunity/PathOfBuilding-PoE2)**: 
use this when you want release notes, issue tracking, or the newest
PoE2 build planner downloads.
- **[pobb.in](https://pobb.in/)**: 
share a Path of Building setup as a short browser-friendly link.

## Crafting and item research

- **[Craft of Exile](https://www.craftofexile.com/?game=poe2)**: 
modifier lookup, crafting calculator, simulator, and emulator for
testing an item plan before spending currency in game.
- **[Path of Exile 2 Wiki](https://www.poe2wiki.net/wiki/Path_of_Exile_2_Wiki)**: 
community-maintained reference hosted by GGG, useful for mechanics,
item explanations, and source links.

## Loot filters and search strings

- **[FilterBlade](https://filterblade.xyz/)**: 
customize NeverSink-style loot filters and adjust strictness, colors,
sounds, and rules for your stage of progression.
- **[poe2.re](https://poe2.re/)**: 
generate regex strings for vendor searches, maps, Expedition, and
other in-game search boxes.
